# 裁决边界与档位

固定四维，逐档定义以 assets/rules.json 为唯一来源，各方0～20分。分数越高表示现有证据支持的行为过错越重；5分不等于“整个人完全错误”。不对双方分数归一化，不输出责任比例。

0：有足够上下文审查而未发现明显过错。null：无法审查，或安全模式暂停；不得以“没有证据”直接给0。只见一句“哦”，不能推出轻蔑，也不能宣布对方四维全无过错。可以给已能核实的维度评分，把其余维度保留null。

每维取最高满足证据要求的档位；没有达到更高档的证据就使用较低档，不因措辞生气而升级。重复次数不是加分公式。频次、已知约定、是否收到澄清、影响和可避免性是解释档位的依据，不能猜测动机。

每个独立事件仅分配一个维度。例：“你这种人没救了”归communication；不能同时以“伤害感情”“冲突升级”再计resolution。另一次明确以失联惩罚对方才可能独立计resolution。引用同句中多个行为时，拆成不重叠原文并解释各自独立事件；自动校验无法辨认改写后重复事件，人工仍需复核。

只在关键事实充分、双方四维均非null时比较总分。v2 lowTotal=0、closeGap=0：双方全0为none；同分且非0为close；其他按较高分显示A/B。1分差只是规则结果，不表示科学显著或一方全责。严重单项仍单独展示，不让另一方多个轻微问题冲淡。安全风险退出排名，不把防御性反应机械等同施害。

需核实约定是否双方自愿、可协商；无“恋人必须秒回/必须交出密码/必须接受道歉”的默认义务。明确约定暂停不等于冷处理，受威胁者不回应不算回避。合理提出分手不等于威胁；是否借此强迫服从须看原文行为。
