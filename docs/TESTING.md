### 规则与模型校验

- 两方独立求和、低分不制造过错方、接近分数处理、任何缺项不当0、关键事实不足不强判。
- 动态增加第五个维度及改变最高分时，Schema/校验/总分依照配置工作；页面按规则数组渲染。
- 拒绝超范围/负数/小数分数、缺失维度、无效来源引用、同一具体行为跨维度重复计分。
- 身份交换同时交换当事人材料、叙述中的甲乙标签、图片归属和引用；过错倾向跟随具体行为。
- 安全风险暂停评分；单方模式不形成完整双人责任结论。
- 普通私人材料的Mock不产生虚构分数；八个虚构案例参考输出分别符合预期。
- 本地模拟提供商实际接收到**多模态图片、人物标注和JSON Schema**；并发请求只产生一次模型调用，程序计算总分及可得费用。
- 无效模型输出返回明确错误代码，不保存替代判决，案件恢复可重试状态，日志不含原始响应内容。

### 流程与隐私

- 未授权/其他案件凭证不能读取案件和图片；角色由凭证决定，请求体夹带role等字段被拒绝。
- 双方提交前乙方无法读取甲方陈述或截图；双方完成后可见。
- 原始陈述提交锁定，相同请求重复提交幂等，不同内容返回冲突。
- 截图人物标注、归属、顺序、格式和重复ID校验；提交后禁止再增删证据。
- 真实JPEG/PNG重编码，拒绝伪装图片；图片不能通过静态目录获取。
- SQLite关闭并重新打开后仍保留案件、原陈述和双方权限。
- 删除案件级联清理图片，原凭证失效；过期案件清理。
- 开发者接口在开发环境同样需要独立凭证，只能选择虚构案例；不接受真实caseId；生产环境返回404。
- 浏览器同设备流程实际选择本地图片、上传、标注、切换角色、审理并删除。异地流程使用两个独立浏览器上下文，并刷新确认恢复。

## 当前已知限制

1. 没有模型密钥时普通案件只给不可评分的Mock流程结果；不能据此判断真实纠纷。实验室的人工参考分数不证明真实模型推理、身份公平性或安全识别可靠。
2. 基于能力凭证，没有实名/账号系统。邀请持有者拥有乙方权限，创建者也知道邀请；它不证明实际填写者的真实身份。同设备隐私依赖参与者不擅自操作他人的本地环境。
3. 单进程本地后端；进程崩溃后可能需要重试外部调用，无法保证第三方计费的跨崩溃exactly-once。普通并发和已持久化判决的重复请求已经验证幂等。
4. JSON/来源存在性/行为标识校验无法证明模型的事实解释正确，也不能完全识别用不同名称对相同行为重复评分。未经真实模型回归，不应声称评分质量已验收。
5. 没有证据真伪鉴定、账号恢复或证据追加；这些不属于本轮范围。截图压缩可能影响细小文字，需真机/真实模型测试确认可读性。
6. H5构建有两项webpack包体积提示（约313 KiB入口、约399 KiB页面chunk），未阻止运行；微信产物当前约476 KiB。依赖安装存在上游弃用提示，不等于相关功能测试失败。
7. 数据未做应用层静态加密；SQLite删除不承诺第三方模型、云磁盘快照或备份的物理擦除。仅适用于受信任机器上的本地Demo。

## 重现

```sh
npm ci
npm run typecheck
npm test
npm run build:h5:dev
npm run test:e2e
npm run build
npm run test:production
```

首次在其他机器运行浏览器测试前安装 Chromium：`npx playwright install chromium`。测试输出是当前运行生成的 `test-results/e2e-results.json`、`production-results.json`，失败trace分别存于专用子目录。浏览器预览截图也保存在 `test-results/`。构建命令在写入产物前清理相应目标目录，防止开发者页面的旧chunk混入生产目录。
